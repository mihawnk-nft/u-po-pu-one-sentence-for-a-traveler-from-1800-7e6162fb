> Picture a single road joining every library and post office on earth, so that a letter you send reaches the far side of the world before the ink on it is dry.

One sentence, 158 characters, explaining the modern internet to a time traveler from 1800. It builds only from things a person from that year already knows — a road, a library, a post office, a letter, ink — and the single comparison carries the whole picture: the internet is a road joining all the world's storehouses of knowledge and all its messengers, and anything sent on it arrives at once. No word in it was coined after 1800.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt`. Pure Python stdlib, no network, fully deterministic.
